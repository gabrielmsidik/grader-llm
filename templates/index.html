Grader LLM API Documentation

POST /grade

Grades a student's answer based on the provided question and actual answer.

Request Body:

{
    "question": "string",
    "actual_answer": "string",
    "student_answer": "string",
    "documents": ["string"]
}

Response:

{
    "score": "float (0-2)",
    "feedback": "string",
    "reason_code": "enum (CORRECT, SOURCE_CORRECT, HALLUCINATION, INVALID_INPUT, IDK)"
}

Example:

curl -X POST http://localhost:5000/grade \
-H "Content-Type: application/json" \
-d '{
    "question": "What is the capital of France?",
    "actual_answer": "Paris",
    "student_answer": "Paris",
    "documents": ["France is a country in Europe.", "Paris is the capital of France."]
}'
Question is required
Actual answer is required
Student answer is required
